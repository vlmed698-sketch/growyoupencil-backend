# GrowYouPencil — backend

Провайдит три вещи, которых не хватало в чисто статичной версии на GitHub Pages:

- **Авторизация Telegram** — проверка подписи `initData`, которую присылает Mini App.
- **Общая база игроков** — единый рейтинг для всех, кто открывает бота.
- **Оплата лечения через Telegram Stars** — создание счёта и подтверждение оплаты.

GitHub Pages отдаёт только статику и не умеет запускать код, поэтому это отдельный
Node.js-процесс, который нужно захостить где-то ещё (см. ниже).

## Локальный запуск

```bash
cd backend
npm install
cp .env.example .env
# впишите в .env реальный BOT_TOKEN из @BotFather
npm start
```

Сервер поднимется на `http://localhost:3000` и одновременно запустит бота (long polling),
поэтому бот и API работают в одном процессе — токен нужен только один раз.

## Деплой (рекомендуется Railway)

GitHub Pages для этого не подходит — нужен хостинг, который держит процесс запущенным
постоянно. Проще всего с **Railway** (есть бесплатный лимит, деплой из репозитория в пару кликов):

1. Залейте папку `backend/` в отдельный GitHub-репозиторий (например `growyoupencil-backend`).
2. На railway.app → New Project → Deploy from GitHub repo → выберите этот репозиторий.
3. В Variables добавьте `BOT_TOKEN` (и при желании `CURE_PRICE_STARS`).
4. Railway сам определит Node.js-проект и запустит `npm start`. После деплоя скопируйте
   публичный URL вида `https://growyoupencil-backend-production.up.railway.app`.

Альтернативы: Render.com (Web Service, план Free можно "усыпить" — для бота с polling это
проблема, потребуется платный "Always On"), Fly.io, обычный VPS с `pm2`.

⚠️ **Важно про базу данных.** Игроки сейчас хранятся в файле `db.json` рядом с сервером
(через `lowdb`). На большинстве бесплатных хостингов диск не переживает передеплой —
для реального продакшена стоит перейти на постоянную БД (например Postgres на Supabase/Neon).
Для MVP и тестов текущего варианта достаточно.

## Подключение фронтенда

В `index.html` (файл, который лежит на GitHub Pages) есть константа:

```js
const API_BASE = 'https://ВАШ-БЭКЕНД.example.com';
```

Замените её на реальный URL после деплоя backend — и закоммитьте изменение в
`growyoupencil.github.io`. Без этого приложение просто продолжит работать в
локальном офлайн-режиме (как раньше), ничего не сломается.

## Эндпоинты

| Метод | Путь                 | Что делает |
|-------|----------------------|------------|
| POST  | `/api/me`             | Проверяет initData, регистрирует/обновляет игрока, отдаёт его данные |
| GET   | `/api/leaderboard`    | Топ-20 игроков по показателю |
| POST  | `/api/tease`          | Действие «Потеребонькать» с серверным кулдауном 24ч |
| POST  | `/api/duel/result`    | Записывает исход дуэли (+3 / −2) |
| POST  | `/api/cure/invoice`   | Создаёт ссылку на оплату лечения через Telegram Stars |
